#  AI Support Assistant (Enterprise RAG System)

##  Опис проєкту
Цей проєкт — це Machine Learning мікросервіс, інтегрований з Telegram, який виконує роль "розумного" асистента служби підтримки. Система аналізує запити користувачів, знаходить релевантний контекст у локальній векторній базі даних (Qdrant) та генерує відповіді за допомогою великої мовної моделі (LLM). Проєкт демонструє побудову RAG-архітектури (Retrieval-Augmented Generation), інтеграцію з месенджером, складну маршрутизацію через n8n (з автоматичною ескалацією на оператора) та повну контейнеризацію системи.

---

##  Стек технологій
* **Backend:** FastAPI, Pydantic, Python 3.11
* **Machine Learning & AI:** LangChain, HuggingFace Embeddings, Groq API (Qwen)
* **Database & Routing:** Qdrant (Vector DB), n8n, Telegram API (Long Polling & Webhooks)
* **DevOps:** Docker, Docker Compose

---

##  Що було реалізовано (Features)
* **Контекстний пошук (RAG):** Налаштовано пайплайн векторизації корпоративної бази знань (документів) для точного семантичного пошуку інформації.
* **Автоматизована маршрутизація (n8n):** Побудовано візуальний workflow, який перехоплює повідомлення, визначає інтенції користувача та гнучко керує логікою діалогу.
* **Ескалація на оператора:** Реалізовано інтелектуальну fallback-логіку — якщо в базі знань немає релевантної інформації, система автоматично надсилає HTTP-запит до FastAPI для перемикання діалогу на живого спеціаліста.
* **Observability (Моніторинг):** Налаштовано трансляцію логів у реальному часі для відстеження вхідних JSON-пакетів від Telegram, статусів пошуку та HTTP-запитів.
* **Ізольоване середовище:** Вся архітектура загорнута в Docker Compose, що забезпечує безшовну та безпечну комунікацію між контейнерами (FastAPI, Qdrant, n8n) у спільній внутрішній мережі.

##  Як запустити локально

**1. Клонуйте репозиторій та перейдіть у робочу директорію:**
```bash
git clone https://github.com/ignat4/telegram-rag-support-bot.git
cd telegram-rag-support-bot
```
**2. Налаштуйте змінні оточення:**
Створіть файл `.env` у кореневій папці проєкту та додайте необхідні ключі доступу:

```env
GROQ_API_KEY=ваш_ключ_groq
TELEGRAM_BOT_TOKEN=ваш_токен_бота
N8N_WEBHOOK_URL=http://n8n:5678/webhook/telegram-webhook
```
**3. Зберіть та запустіть контейнери:**
*(Переконайтеся, що Docker Desktop запущено)*

```bash
docker compose up -d --build
```
**4. Налаштуйте логіку n8n (Імпорт схеми):**
Оскільки проєкт розгортається в ізольованому середовищі, візуальний редактор n8n буде порожнім. Для завантаження логіки:

* Відкрийте у браузері  `http://localhost:5678`
* Створіть локальний акаунт власника (можна використати будь-які тестові дані, наприклад `admin@test.com` / `123456`, підтвердження пошти не вимагається).
* Після входу в систему відкрийте термінал на вашому комп'ютері та виконайте команду імпорту:

  ```bash
  docker compose exec n8n n8n import:workflow --input=/data/Telegram_RAG.json
  ```

* Оновіть сторінку в браузері (F5), відкрийте імпортовану схему та переведіть перемикач у правому верхньому куті в положення **Active**.

**5. Протестуйте бота та увімкніть логування:**
Щоб бачити, як система аналізує повідомлення "під капотом", увімкніть трансляцію логів у терміналі:

```bash
docker compose logs -f backend
```
